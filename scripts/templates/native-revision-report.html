What changed in v2

  • Acquisition. A Schmidl-Cox metric over the two identical training blocks detects frames regardless of carrier offset. Fine timing uses an FFT correlation with a segmented fallback, and the one-block ambiguity in the offset estimate is resolved by three coherent hypotheses.
  • Streaming in C++. Each sample enters a running metric once, and decoding runs only at detection peaks. Python crosses the C interface once per transport chunk instead of once per 256-sample hop.
  • Early header rejection. After the first data symbol the receiver checks 40 known header bits and drops frames for other destinations. This costs no delivery: the Chase search fixes at most two bits.
  • Static 16-QAM. Gray-mapped 16-QAM on data tones, configured at both ends. QPSK stays the default and its waveform is byte-identical to v1. The liquid comparator gained a matched 16-QAM payload mode.
  • Chase switch. The bounded CRC-aided Chase search can be disabled, so its effect is measured rather than assumed.
